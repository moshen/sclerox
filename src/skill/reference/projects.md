# Projects

```bash
sclerox project search "<description>"
sclerox project get <id>
sclerox project add --name "<name>" [--description "<desc>"] [--link "url|label"]
sclerox project people add|remove|list <project_id> <person_id> [--role "<role>"]
sclerox project meetings add|remove|list <project_id> <meeting_id>
sclerox project repos add|remove|list <project_id> <repo_id>
```

Linking a repo to a project is part of the repo workflow - see
[repos-and-code.md](repos-and-code.md).
