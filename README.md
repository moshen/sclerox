# Sclerox

![Sclerox Logo](README/sclerox-logo.svg)

A SQLite-backed personal knowledge base for AI-augmented engineering. Sclerox
indexes your code repos, meeting notes, todos, research investigations, and
memories. All with a single executable.

## Why?

There are a plethora of implementations of durable memory replacement and search
systems for local agents. This one has largely been generated in a guided way as
an experiment and as an effort to explore creating my own agent tooling.

After reading through a few other implementations, their requirements for full
functionality amounted to installing a locally running distributed system, or a
loose collection of tools. I mostly wanted something that was easy to install
and reason about, all while being backed by a database that could be read
indepenent of the tool itself (in this case sqlite).

I'm continuing to use this too daily, while expanding the capabilities and
fixing bugs. If you've come to rely on this, please feel free to drop a message
in the issues for any feature requests or bug reports.

## Install

Download a release binary. Or...

### mise

Releases publish a binary for each platform on every push to `main`. Install
the latest with [mise](https://mise.jdx.dev) using the `github:` backend:

```sh
mise use -g "github:moshen/sclerox"
```

This downloads the release archive matching your OS/arch and adds the
extracted binary's directory to your PATH so `sclerox` is directly invokable.

If your `mise.toml` pins a specific version, the equivalent config is:

```toml
[tools."github:moshen/sclerox"]
version = "latest"
```

Use `mise ls-remote github:moshen/sclerox` to see available versions. A
specific version can be installed with
`mise use -g "github:moshen/sclerox@<version>"`.

### From source

```bash
cargo install --path .
```

### Setup (either install method)

```bash
sclerox install          # sets up Claude Code skill + hooks + global gitignore
```

`sclerox install` writes:
- `~/.claude/skills/sclerox-kb/` - skill dir: `SKILL.md` + `reference/*.md` (or `~/.config/opencode/skills/` for OpenCode)
- `~/.claude/settings.json` - `SessionStart` and `Stop` hooks that auto-index repos and distill memories
- `~/.config/git/ignore` - excludes `.sclerox/` from all repos

## Quick start

```bash
# Index a repo (embeddings generated by default)
sclerox repo index ~/code/my-service

# Search code
sclerox code search "FinancialDocument"
sclerox code search --repo my-service "createJob"

# Global search across everything
sclerox search "auth latency"

# Todos
sclerox todo list
sclerox todo add --title "Review PR #123" --category github
sclerox todo done 42 --note "merged"

# Memory
sclerox memory set "auth-approach" "use JWT for stateless auth" --type project
sclerox memory search "JWT"
sclerox memory import --agent claude    # import from Claude Code auto-memory files
```

## Commands

### `sclerox search <query>`
Global full-text search across memory, people, meetings, projects, todos, investigations, and code symbols.

### `sclerox code search [--repo <name>] <query>`
Search symbols across all indexed repos. `--repo` filters by repo name substring.

### `sclerox repo`
| Command | Description |
|---------|-------------|
| `sclerox repo index [path]` | Index a repo (embeddings on by default) |
| `sclerox repo index --no-embed` | Index without embedding generation |
| `sclerox repo list` | List all indexed repos |
| `sclerox repo search <query>` | Find repos by name/description (FTS + semantic) |
| `sclerox repo show [path]` | Show indexed files and symbol counts |
| `sclerox repo unindex [path]` | Remove a repo from the registry |
| `sclerox repo search-symbols <query>` | Search symbols across all indexed repos (self-healing) |
| `sclerox repo sync [--force]` | Remove stale entries, reindex missing DBs, migrate old schemas |
| `sclerox repo reembed [--repo <name>] [--force]` | Backfill embeddings for chunks that don't have one |

### `sclerox memory`
| Command | Description |
|---------|-------------|
| `sclerox memory set <key> <value>` | Set a memory (types: general, user, feedback, project, reference) |
| `sclerox memory get <key> [--history]` | Get a memory by key |
| `sclerox memory list [--type <t>] [--all]` | List memories (active only by default) |
| `sclerox memory search <query>` | FTS search (active memories only; `--all` includes stale) |
| `sclerox memory delete <key>` | Delete a memory permanently |
| `sclerox memory stale <key>` | Mark as stale (preserved for history) |
| `sclerox memory supersede <old> <new> <value>` | Replace with traceable back-link |
| `sclerox memory review <key>` | Mark a memory as reviewed |
| `sclerox memory needs-review [--days 30]` | List memories not reviewed recently |
| `sclerox memory conflicts` | List unresolved near-duplicate conflicts from distillation |
| `sclerox memory reembed [--force]` | Backfill embeddings for memories that don't have one |
| `sclerox memory distill [<key>\|--from <file>]` | AI-compress via the `[ai].command` (default `claude -p …`) |
| `sclerox memory import --agent claude` | Import from Claude Code auto-memory |
| `sclerox memory people add\|remove\|list <key> <person_id>` | Link people to a memory entry |

### `sclerox todo`
| Command | Description |
|---------|-------------|
| `sclerox todo list [--status open\|done\|watch\|all]` | List todos |
| `sclerox todo add --title <title>` | Add a todo |
| `sclerox todo get <id>` | Get a todo by ID |
| `sclerox todo search <query>` | Full-text search todos (includes done items) |
| `sclerox todo update <id> [--title\|--notes\|...]` | Edit a todo's fields |
| `sclerox todo done <id> [--note]` | Mark done |
| `sclerox todo watch <id>` | Convert to watch item |
| `sclerox todo reopen <id>` | Reopen |
| `sclerox todo history [<query>]` | Search completed todos |
| `sclerox todo delete <id>` | Delete a todo permanently |
| `sclerox todo people add\|remove\|list <id> <person_id>` | Link people |
| `sclerox todo projects add\|remove\|list <id> <project_id>` | Link projects |

### `sclerox meeting`
| Command | Description |
|---------|-------------|
| `sclerox meeting add --title <t> --date <d>` | Add meeting (embeddings on by default) |
| `sclerox meeting get <id>` | Get a meeting by ID |
| `sclerox meeting search <query>` | FTS + semantic similarity search combined |
| `sclerox meeting update <id> [--title\|--notes\|...]` | Update a meeting's fields |
| `sclerox meeting delete <id>` | Delete a meeting |
| `sclerox meeting people add\|remove\|list` | Manage attendees |

### `sclerox research`
| Command | Description |
|---------|-------------|
| `sclerox research start --name <n> --slug <s>` | Start investigation |
| `sclerox research get <id_or_slug>` | Get an investigation by ID or slug |
| `sclerox research list [--status open\|concluded\|all]` | List investigations |
| `sclerox research search <query>` | FTS + semantic similarity search combined |
| `sclerox research update <id> [--name\|--plan\|--findings]` | Update plan, findings, or status |
| `sclerox research add-source <id> --url <url>` | Add evidence URL |
| `sclerox research sources <id>` | List sources for an investigation |
| `sclerox research conclude <id> --findings <f>` | Record findings (required) |
| `sclerox research reopen <id>` | Reopen concluded investigation |
| `sclerox research delete <id>` | Delete an investigation permanently |
| `sclerox research people add\|remove\|list <id> <person_id>` | Link people |
| `sclerox research projects add\|remove\|list <id> <project_id>` | Link projects |

### `sclerox project`
Manage projects with links to repos, meetings, people, and todos.

```bash
sclerox project add --name "Auth Service" --description "..." --link "url|GitHub"
sclerox project repos add|remove|list <project_id> <repo_id>
sclerox project meetings add|remove|list <project_id> <meeting_id>
sclerox project people add|remove|list <project_id> <person_id> [--role lead]
sclerox project links add|remove|list <project_id> <link>
```

### `sclerox people`
```bash
sclerox people add --name "Alice" --email "alice@example.com" --github alicegit
sclerox people search "alice"
```

## Configuration

Tunables live in `~/.config/sclerox/config.toml` (created, all-commented, by `sclerox install`).
Precedence, highest first: **CLI flag > env var > config file > built-in default**.

```bash
sclerox config show          # effective settings (file + env + defaults, merged)
sclerox config init          # write a commented config.toml (--force to overwrite)
sclerox config path          # where the file lives
```

Configurable sections include `[ai]` (distillation command/model), `[search]`
(`semantic_threshold`, `semantic_limit`), `[dedup]` thresholds, `[memory]`
(`max_value_chars`), `[session_context]` sizes, `[distill]` chunking, `[embed]`
chunk size, `[index]` (`max_file_bytes`, `max_files`, `auto`), `[install]`
(which managed artifacts get refreshed on reinstall), and `[log] level`. Run
`sclerox config init` to see every key with its default.

`[ai].command` is the full distillation command (the transcript prompt is
appended as the last argument). If unset, sclerox uses the built-in default for the
agent that invoked it - `claude -p --safe-mode --no-session-persistence --tools=`
or `opencode run --pure`.

Environment variables still work and override the file:

| Variable | Default | Description |
|----------|---------|-------------|
| `SCLEROX_CONFIG` | `~/.config/sclerox/config.toml` | Config file path |
| `SCLEROX_DB` | `~/.local/share/sclerox/sclerox.db` | Primary database path |
| `SCLEROX_LOG` | off | Log level: `error\|warn\|info\|debug` -> `~/.local/state/sclerox/logs/sclerox-YYYY-MM-DD.log` |
| `SCLEROX_AI_COMMAND` | agent default | Full distillation command (prompt appended last) |
| `SCLEROX_AI_MODEL` | agent default | Model appended to the default command |
| `SCLEROX_MAX_INDEX_FILE_BYTES` | `1000000` | Files larger than this use line-based chunking instead of tree-sitter |
| `SCLEROX_MAX_INDEX_FILES` | `50000` | Reject folders over this many files (`--force` to override) |

## How hooks work

After `sclerox install`, two Claude Code lifecycle hooks are active:

- **`SessionStart`** - `sclerox hook start` indexes the current repo if it has a `.git` directory (incremental, fast)
- **`Stop`** - `sclerox hook stop` re-indexes the repo, then spawns a background
  process that distills session memories via `claude -p` and stores them in
  `sclerox memory`

Distillation is tracked per-session: re-runs only when the session has grown by 50+ new turns.

## Supported languages

Tree-sitter parsing (full symbol extraction): Rust, Python, TypeScript,
JavaScript, Go, C#, Java, C/C++, Ruby, Kotlin, SQL, Shell

Line-based chunking (indexed but no symbol extraction): Swift, Scala, PHP, Markdown

All indexed content is searchable via `sclerox code search` and `sclerox search`.
